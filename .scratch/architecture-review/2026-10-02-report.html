32 spellings become 12. The Content page already reads its Unicode ranges this way.

Problem
Twelve closed lists, such as statuses, segments, app types and field character sets, are spelled 32 times across nine files, so adding the GFT segment took three hand edits and an update to the test that pins the option list.
Solution
One Python module owns the lists, every page embeds them as JSON the way the Content page already embeds _unicode_character_ranges, and the JavaScript and templates read them from there.
Wins
  • A new segment is one edit
  • 32 spellings become 12
  • Leverage: eight files read one table
  • Copy-pinning tests become unnecessary

DATA_MAP §12 records that the provisioning seed differed between the two sides until 2026-09-14. None of the 156 browser tests calls a rule directly.

Problem
30 of the 42 rules in DATA_MAP §12 are logic written once in Python and again inside app.js closures that read report from scope, and the map names one contract test between them, for generation readiness alone.
Solution
Treat those rules as one module with two adapters, the Python one and a DOM-free JavaScript file that takes the report as an argument, and hold both to one shared table of rule cases.
Wins
  • Drift fails a shared case
  • JavaScript rules testable without page flows
  • Readiness leaves the Word renderer
  • Closures stop owning rules
Decided in DATA_MAP §12: list paste and the retest Limitations sentence are client-only on purpose. They stay out of this module.

Open for the grilling: keep the JavaScript adapter, or delete it for some rules and let the page ask the server.

Problem
Each convention the document prints is spelled once in docx_report.py and again in docx_import.py, and the writer imports two of its own constants from the reader.
Solution
One module owns each printed convention as a print and read pair, including which master template a report gets, and both the generator and the importer call it.
Wins
  • A format change edits one module
  • Round-trip case per convention
  • Writer stops importing from the reader
  • Asia decided in one place
